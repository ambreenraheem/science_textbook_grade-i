# Placeholder Images

This directory contains placeholder images for development and testing.

## Generating Placeholders

Run the Python script to generate placeholder images:

```bash
python static/images/placeholders/generate_placeholders.py
```

This will create:
- **Chapter placeholders** (400x300): chapter-placeholder.png, living-nonliving.png, plants.png, animals.png, food.png
- **Lesson placeholders** (600x400): lesson-placeholder.png

## Colors

Placeholders use the child-friendly color palette from research.md:
- Sky Blue: #87CEEB
- Grass Green: #90EE90
- Soft Pink: #FFB6C1
- Sunshine Yellow: #FFD700

## Replacing with Real Images

Replace these placeholders with actual illustrations:
1. Ensure images are appropriate for Grade-1 students (ages 6-7)
2. Use bright, clear, simple illustrations
3. Maintain aspect ratios: 4:3 for chapters (400x300), 3:2 for lessons (600x400)
4. Optimize file sizes (<200KB per image)
5. Use WebP format for better performance
